# Bioinformatics Portfolio

I am a BS Biotechnology student in Pakistan, working towards a Master's in bioinformatics from a good university. This repo is where I'm tracking my self-taught path into the field, starting from Python basics and building up toward real genomic analysis.

I started this because my university's bioinformatics course didn't go very deep, so I'm learning most of it on my own, one concept at a time, using resources like Coursera to audit courses relevant to my field, AI as a tutor to learn concepts and debug my code, and Rosalind to practice on real problems as I go.

## What's in here so far

- `01_counting_nucleotides.py` — counts how many times each base (A, C, G, T) shows up in a DNA sequence
- `02_dna_into_rna.py` — transcribes a DNA sequence into RNA
- `03_reverse_complement.py` — finds the reverse complement of a DNA sequence
- `04_gc_content.py` — reads a multi-sequence FASTA file and finds which sequence has the highest GC content
- `05_counting_point_mutations.py` — compares two equal-length DNA sequences and counts how many positions differ

Each one is a Rosalind problem I solved and actually understand line by line.
